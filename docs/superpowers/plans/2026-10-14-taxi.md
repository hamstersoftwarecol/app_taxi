# Rayo Implementation Plan

> Ejecución inline con pruebas y revisión por etapa.

**Goal:** entregar plataforma local de reservas con panel y código móvil Android/iOS.
**Architecture:** web y móvil consumen gateway; identidad, viajes y tracking son servicios independientes con SQLite.
**Tech Stack:** Next.js, React, Expo, Node, Express, SQLite.
**Spec:** docs/superpowers/specs/2026-10-14-taxi-design.md

## Restricciones

Español, Bogotá, COP, demo explícita, ningún cobro real, permisos por rol, persistencia y estados válidos.

## Task 1: dominio y servicios

Archivos: packages/shared/domain.mjs, services/{auth,trips,tracking,gateway}/server.mjs, tests/domain.test.mjs, tests/api.test.mjs.
Interfaz: createTrip(input, actor), transitionTrip(id, status, actor), listTrips(actor), JWT con sub/role/exp, GET/POST /api/trips, PATCH /api/trips/:id, GET /api/drivers, GET /api/locations.
